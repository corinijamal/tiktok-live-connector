# ساحة المعركة — TikTok Battle Arena

لعبة معركة فردية للبث المباشر على TikTok. المشاهدون ينضمون بكتابة "انضم"
أو بأول تعليق، ويظهرون كفقاعات بصورهم الشخصية داخل ساحة دائرية. كل إعجاب
(لايك) يضيف نقطة، والاصطدامات بين اللاعبين تسبب ضررًا، والهدايا تمنح
تعزيز هجوم مؤقت.

## آلية اللعبة

- **الانضمام**: كتابة "انضم" في الشات، أو أول تعليق يكتبه المشاهد.
- **النقاط**: كل لايك = ‎+1 نقطة خضراء لصاحبه.
- **الاصطدام**: عند تصادم فقاعتين، كل طرف يفقد نقاطًا بمقدار "هجوم" الطرف
  الآخر (الهجوم الأساسي = 1).
- **تعزيز الهدايا**: أي هدية تمنح هجومًا إضافيًا لمدة 10 ثوانٍ يساوي عدد
  عملات الهدية بالضبط (هدية بـ50 عملة = ‎+50 هجوم لكل اصطدام خلال 10 ثوانٍ).
- **المستوى**: تراكم النقاط يكبّر حجم الفقاعة حتى حد أقصى، ثم تُمنح شارة
  مميزة (🥉 🥈 🥇 👑) بدل الاستمرار بالتكبير.
- **الجولات**: كل جولة 3 دقائق. الفائز هو صاحب أعلى نقاط عند انتهاء الوقت.
  تبدأ جولة جديدة تلقائيًا حتى يتم إيقاف اللعبة يدويًا من لوحة التحكم.

## التشغيل محليًا

```bash
npm install
npm start
```

بعدها افتح `http://localhost:3000` في المتصفح.

من لوحة التحكم أسفل يمين الشاشة:
1. اكتب اسم المستخدم على TikTok (بدون @) واضغط "اتصال بالبث".
2. اضغط "بدء اللعبة" لبدء الجولة الأولى.
3. اضغط "إيقاف اللعبة" لإيقاف الجولات المتتالية.

## الاختبار بدون بث مباشر

لتجربة اللعبة بدون الاتصال الفعلي بـ TikTok، استخدم نقاط الاختبار هذه:

```bash
# إنشاء لاعب
curl -X POST http://localhost:3000/api/simulate/join \
  -H "Content-Type: application/json" \
  -d '{"userId":"test1","nickname":"أحمد","profilePictureUrl":"https://i.pravatar.cc/150?img=1"}'

# إرسال إعجابات
curl -X POST http://localhost:3000/api/simulate/like \
  -H "Content-Type: application/json" \
  -d '{"userId":"test1","count":5}'

# إرسال هدية (قيمة عملات)
curl -X POST http://localhost:3000/api/simulate/gift \
  -H "Content-Type: application/json" \
  -d '{"userId":"test1","coinValue":50}'
```

## اختبار منطق اللعبة

```bash
node test-engine.js
```

يتحقق هذا الملف من: إضافة النقاط باللايك، احتساب الهجوم المعزز من
الهدايا، وتوزيع الضرر عند التصادم.

## النشر على Render

نفس أسلوب مشاريعك السابقة:
1. ادفع المشروع إلى GitHub.
2. أنشئ Web Service جديد على Render، اربطه بالمستودع.
3. Build Command: `npm install` — Start Command: `npm start`.
4. فعّل Auto-Deploy من إعدادات GitHub integration.

## هيكل الملفات

```
battle-arena/
├── server.js              # نقطة الدخول: Express + Socket.io + اتصال TikTok
├── server/
│   └── gameEngine.js       # منطق اللعبة: اللاعبين، الفيزياء، الاصطدام، الجولات
├── public/
│   └── index.html          # واجهة الساحة (تُعرض كـ overlay فوق البث)
├── test-engine.js          # اختبار منطق اللعبة بمعزل عن الشبكة
└── package.json
```

## نقاط قابلة للتخصيص لاحقًا

- ثوابت اللعبة كلها في أعلى `server/gameEngine.js`: مدة الجولة، مدة
  التعزيز، الحد الأقصى لحجم الفقاعة، عتبات الشارات.
- الكلمة المفتاحية للانضمام حاليًا `"انضم"` — يمكن تغييرها من متغير
  `JOIN_KEYWORD` في `server.js`.
- لا يوجد حفظ دائم (MongoDB) في هذه النسخة الأولى — كل البيانات في
  الذاكرة وتُصفّر عند إعادة تشغيل السيرفر. يمكن إضافتها لاحقًا لحفظ
  سجل الفائزين بين الجلسات، بنفس طريقة مشروع الأسئلة.
