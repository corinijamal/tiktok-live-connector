# ساحة المعركة — TikTok Battle Arena

لعبة معركة فردية للبث المباشر على TikTok. المشاهدون ينضمون بتعليق + 20
إعجابًا، ويظهرون كفقاعات بصورهم الشخصية داخل ساحة دائرية يتصادمون فيها،
مع نظام مستويات (رتب) وهجمات هدايا وتأثيرات صوتية وبصرية.

## آلية اللعبة

- **الانضمام**: يحتاج المشاهد شرطين معًا — أن يكتب أي تعليق، وأن يضغط
  ❤️ الإعجاب 20 مرة على الأقل. أيهما تحقق أخيرًا "يفعّل" الانضمام، ويدخل
  المشاهد الساحة بعدد نقاطه المتراكمة من الإعجابات (لا تقل عن 20).
- **النقاط بعد الانضمام**: كل إعجاب/نقرة إضافية = ‎+10 نقاط خضراء مباشرة.
- **الاصطدام**: عند تصادم فقاعتين، كل طرف يفقد نقطة واحدة من الطرف الآخر.
  إذا وصلت نقاط أحدهم إلى صفر، **يخرج من الساحة فورًا** ويُمنح الطرف الآخر
  "قتلة" (kill) تظهر بجانب اسمه (💀 العدد).
- **هجوم الهدايا**: أي هدية تُطلق "قذيفة" من فقاعة المُرسِل باتجاه صاحب
  أعلى نقاط حاليًا في الساحة، وتُلحق به ضررًا يساوي عدد عملات الهدية
  بالضبط. تظهر رسالة "قام <المرسل> بتفعيل المستوى <الرقم>" حسب قيمة
  الهدية (1–6)، مصحوبة بصوت.
- **الرتب (المستويات)**: تراكم النقاط يكبّر حجم الفقاعة حتى حد أقصى (1000
  نقطة، أي 100 نقرة)، وبعده تُمنح رتبة مميزة بشكل شفرة منشار معدنية دوّارة
  حول الفقاعة، بلون خاص لكل رتبة:
  🥉 برونزي (1000) → 🥈 فضي (2500) → 🥇 ذهبي (5000) → 💎 ماسي (10000) →
  🔴 ياقوتي (20000) → 👑 أسطوري (40000).
- **الجولات**: كل جولة 3 دقائق. الفائز هو صاحب أعلى نقاط عند انتهاء الوقت.
  تبدأ جولة جديدة تلقائيًا حتى يتم إيقاف اللعبة يدويًا من لوحة التحكم.
  ملاحظة: اللاعبون المُقصَون (Eliminated) لا يعودون تلقائيًا بالجولة
  التالية — يحتاجون يستوفوا شرط الانضمام (تعليق + 20 إعجاب) من جديد.
- **مؤثرات صوتية**: أصوات تصادم وتفعيل مستوى تُولَّد مباشرة بالمتصفح (لا
  تحتاج ملفات خارجية)، وتُفعَّل تلقائيًا عند أول ضغطة على أزرار لوحة
  التحكم (متطلب المتصفحات لتشغيل الصوت).

## لوحة التحكم

لوحة التحكم مخفية افتراضيًا، وتظهر بالضغط على زر الترس ⚙️ أسفل يمين
الشاشة — بحيث لا تبقى ظاهرة فوق البث طول الوقت.

## التشغيل محليًا

```bash
npm install
npm start
```

بعدها افتح `http://localhost:3000` في المتصفح.

1. اضغط زر الترس ⚙️ لإظهار لوحة التحكم.
2. اكتب اسم المستخدم على TikTok (بدون @) واضغط "اتصال بالبث".
3. اضغط "بدء اللعبة" لبدء الجولة الأولى.
4. اضغط "إيقاف اللعبة" لإيقاف الجولات المتتالية.

## الاختبار بدون بث مباشر

```bash
# تعليق (نصف شرط الانضمام)
curl -X POST http://localhost:3000/api/simulate/comment \
  -H "Content-Type: application/json" \
  -d '{"userId":"test1","nickname":"أحمد","profilePictureUrl":"https://i.pravatar.cc/150?img=1"}'

# إعجابات (النصف الآخر — 20+ تفعّل الانضمام إذا كان قد علّق)
curl -X POST http://localhost:3000/api/simulate/like \
  -H "Content-Type: application/json" \
  -d '{"userId":"test1","nickname":"أحمد","count":20}'

# إرسال هدية (قيمة عملات) — تُطلق هجومًا على الأعلى نقاطًا
curl -X POST http://localhost:3000/api/simulate/gift \
  -H "Content-Type: application/json" \
  -d '{"userId":"test1","nickname":"أحمد","coinValue":50}'
```

## اختبار منطق اللعبة

```bash
node test-engine.js
```

يتحقق من: شرط الانضمام (تعليق + 20 إعجاب)، الإقصاء عند وصول النقاط
للصفر واحتساب القتلات، استهداف هجوم الهدايا للأعلى نقاطًا، وتصفير
الساحة عند إعادة الاتصال.

## النشر على Render

نفس أسلوب مشاريعك السابقة:
1. ادفع المشروع إلى GitHub.
2. أنشئ Web Service جديد على Render، اربطه بالمستودع.
3. Build Command: `npm install` — Start Command: `npm start`.
4. فعّل Auto-Deploy من إعدادات GitHub integration.

## ملاحظة حول مكتبة tiktok-live-connector

هذا المشروع يستخدم إصدار `2.4.4` من المكتبة. بيانات المستخدم الفعلية
القادمة من تيك توك غير ثابتة الشكل عبر أنواع الأحداث المختلفة (أحيانًا
تكون متداخلة بعمق غير متوقع)، لذلك `server.js` يبحث عن هوية المرسل
وصورته بشكل تكراري (`findUserDeep` / `findAvatarUrlDeep`) بدل الاعتماد
على مسار ثابت. لو تغيّرت المكتبة مرة أخرى، أول خطوة هي مراقبة سطور
`CHAT EXTRACTED:` / `LIKE EXTRACTED:` في الـ logs للتأكد من نجاح
الاستخراج.

## نقاط قابلة للتخصيص لاحقًا

- كل ثوابت اللعبة في أعلى `server/gameEngine.js`: مدة الجولة، عتبة
  الانضمام (`JOIN_LIKE_THRESHOLD`)، عدد النقاط لكل نقرة
  (`POINTS_PER_LIKE`)، الحد الأقصى لحجم الفقاعة، عتبات الرتب وألوانها
  (`RANKS`)، سرعة الحركة (`MAX_SPEED`).
- مستويات الهدايا (`levelForCoinValue`) قابلة للتعديل حسب قيم الهدايا
  الشائعة في بثوثك.
- لا يوجد حفظ دائم (MongoDB) في هذه النسخة — كل البيانات في الذاكرة
  وتُصفّر عند إعادة تشغيل السيرفر أو تغيير الحساب المتصل.
